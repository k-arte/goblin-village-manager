# Goblin Village Manager

A Foundry VTT settlement/city-builder manager for D&D campaigns.

## Current stage

This repository is a clean module scaffold. The working hotload prototype should be migrated into this structure over versions 0.2-0.4.

## Development priorities

1. Unified effect model.
2. Settlement app UI.
3. Buildings, reforms, orders, bonuses and threat engine.
4. Item/compendium-based buildings.
