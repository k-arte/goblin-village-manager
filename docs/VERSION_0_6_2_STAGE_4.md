# Version 0.6.2 Stage 4

Implemented:

- Resident modifiers foundation.
- Resident salaries are applied during settlement cycles.
- Resident modifiers can affect assigned buildings or the settlement.
- Building and resident services foundation.
- Service order types:
  - instant
  - minor
  - city
- Minor orders are stored on the building.
- Minor order capacity is based on building level by default.
- Action dialog replaced by dark action popover foundation.
- Action popover is styled using the D&D theme accent color.
- Services show source and cost information.

Notes:

- Full player actor active effects and target selection are planned for a later release.
