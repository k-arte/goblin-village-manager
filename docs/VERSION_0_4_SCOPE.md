# Version 0.4.0 Scope

## Implemented

- Modular JS architecture:
  - constants
  - utils
  - data
  - state
  - items
  - cycle
  - dialogs
  - UI
  - main hooks
- Group Actor settlement tab only.
- Settlement Items:
  - buildings
  - reforms
  - orders
  - bonuses
- Item-style UI rows.
- Left click item row: GVM action dialog.
- Right click item row: native Item Sheet.
- Drag ordinary Items into Buildings to import as settlement buildings.
- Basic create dialogs for buildings, reforms, orders and bonuses.
- Cycle engine based on Actor flags and Actor Items.

## Deferred

- Dedicated custom Item Sheets.
- Automated compendium pack generation.
- Advanced effect builder.
- Official bastion conversion library.
- Advanced threat and crisis engine.
