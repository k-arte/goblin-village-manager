# Version 0.7.0 Stage 2

Implemented:

- Ability model foundation.
- Ability modes:
  - add
  - replace
  - upgrade
  - disable
- Ability sources:
  - building
  - resident
  - resident in building
- Building level abilities are collected automatically.
- Resident abilities/services are collected automatically.
- Available abilities are shown in the new "Bonuses and Services" section.
- Unavailable abilities are shown to GM with missing requirements.
- Ability execution foundation:
  - instant
  - minor
  - city
- Ability cards use source art and D&D accent styling.

Notes:

- Ability Builder UI is Stage 3.
- Full active effect target selection is Stage 4.
