- Add real facility catalog.

- Add facility levels, requirements, costs, duration, workers, effects and services.

- Add journal entries for construction and demolition.

## Stage 3: Attacks, losses and loot to treasury

- Add attack resolution.
- Successful defenses add monster loot value to settlement treasury.
- Casualties and military losses are calculated.
- Journal records attack outcome.

## Stage 4: Final integration and release

- Update UI to show journal.
- Connect build picker to facility cards.
- Polish data and release v0.6.0.
