# Version 0.5.1 Scope

## Fixed

- Group Actor tabs no longer become empty after opening the Settlement tab.
- Settlement tab no longer manually applies `display: none` to native D&D5e tabs.
- Loyalty is restored to the resource ribbon.
- Settlement management is displayed above buildings.
- Rename settlement button added.
- Empty Reform, Order and Bonus sections are hidden.
- Sections can be collapsed.
- Basic and special building classification improved.
- Background art uses `data.art || item.img || SAFE_ICON`.
- Button colors and status styling improved.
- Order templates can be displayed and repeated.

## Notes

This is a stabilization and UX hotfix for v0.5.0.
