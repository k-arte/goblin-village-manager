# Version 0.7.0 Scope

## Added

- Inline action drawers inside settlement cards.
- Ability model with add, replace, upgrade and disable.
- Automatic Bonuses and Services section.
- Ability Builder for buildings and key residents.
- Reward Item support for abilities.
- Active effect tracking in settlement cycles.
- Minor order cycle processing.
- Repair as city order.
- Demolition as city order.
- Order cancellation with proportional refunds.
- Player treasury donations.
- Random building damage on failed defense.

## Fixed

- Broken inline image rendering.
- Resident portrait rendering.
- Independent settlement name support.
- Dark readable build picker and ability forms.
- Boons are no longer rendered as a dead card section.

## Deferred

- Full native dnd5e ActiveEffect document creation.
- Expanded official-like facility catalog.
- Advanced target selection UI for every ability.
