# Version 0.6.2 Scope

## Added

- D&D theme accent synchronization.
- Key Residents section.
- Drag-and-drop Actors as key residents.
- Resident configuration.
- Resident worker slots.
- Operation requirements for buildings.
- Requirements can block building operation without blocking construction.
- Resident modifiers and salaries.
- Building and resident services foundation.
- Dark action popover for building actions.
- Minor order foundation.

## Changed

- Boons are no longer rendered on facility cards.
- Key residents visually use the current D&D sheet accent color.
- Building production now respects operation requirements.

## Deferred

- Full target actor active effect application.
- Full city/minor order UI overhaul.
- Expanded official-like facility catalog.
- Compendium generation for all facilities.
