# Version 0.6.0 Stage 2

Implemented:

- Build facility picker.
- Basic/special build lists.
- Build picker only shows unbuilt catalog facilities.
- Build cards show:
  - name
  - category
  - first-level profit
  - cost
  - duration
  - workers
  - requirements
  - services
- Building a facility creates a building Item and an upgrade/build Order.
- Demolish building action.
- Delete building Item action.
- Construction and demolition journal entries.

Notes:

- Attack resolution and loot-to-treasury are Stage 3.
