# Version 0.1 Scope

Version 0.1 is the first working module implementation.

## Purpose

- Load as a real Foundry module.
- Provide a working settlement manager.
- Preserve the core prototype behavior.
- Prepare for refactor into v0.2.

## Included

- Resources
- Buildings
- Projects
- Reforms
- Scouting
- Hidden threat
- Reports
- GM settings
- Senate-based project capacity
- Basic upgrade preview
- Basic workshop/player-service concept

## Not Yet Included

- Full unified effect editor.
- Custom order builder.
- Custom building editor.
- Building Items.
- Compendium support.
- Drag and drop buildings.
- Advanced threat engine.
